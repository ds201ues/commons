## 5/5 agreement

- Nobody said LOCK as a generic shared spreadsheet.
- Speed = **round-trips eliminated**, not pandas. Mint-once: code wins. Say that in the demo.
- Incumbent is **Sheets + Gemini**. Wedge: **BYO agent**, no Google account, rules on the document, URL is the install.
- Remote MCP wrapping the same data is almost equivalent; WebMCP only wins if **this tab’s tools ≠ that tab’s tools** and both humans **watch the write**.
- Identity: agent = **that human’s browser session**. Do not invent agent OAuth.
- Cut: Univer Pro, full CRDT, formula engine, real auth.
- Fallback if two-agent recording fails or the grid is too heavy: **decision / settlement ledger**.

## The product if we take the intersection

**Commons:** a link to a **two-sided table** (client↔freelancer, founder↔investor, housemate split — pick one). You, them, your agent, their agent. Each agent only gets tools for **its column**. Writes are attributed patches everyone sees. Canonical copy is the URL; download is a snapshot. Day one is **two ChatGPT browsers on one origin**, not the grid chrome.
